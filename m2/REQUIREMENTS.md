# User requirements

### Items

- User can add items to inventory.
- Users can create items that are named.
- Users can create items with associated descriptions.
- Users can see whether each item is available, booked or out of service.
- Users can see the same items as a list accross sessions

### Borrowing

- Users can borrow (check out) items that are available.
- Users can return items they have borrowed.
- Users can identify borrowers with their name and email before borrowing.
- Users can see who is currently set as the borrower.
- Users can change who is borrowing.
- Users are told when an item can't be borrowed or returned, and why.
