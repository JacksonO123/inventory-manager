# Specifications

## Functional Specifications

- Users can’t create items with no names
- Users can create items with no description
- Users can create items with the same name
- User cannot check out item without assigning a borrower
- Users cannot create two items with the same ID
- User cannot create items whose name is only spaces
- Leading and trailing whitespaces are removed from item names and descriptions
- New items start with the available status
- User can only check out available items

## Non-Functional Specifications

- User can create item in 2 mouse clicks
- User can see new item immediately after creating it
